# ข้อกำหนดของโมดูลคณิตศาสตร์ (Math Module Specifications)

## ภาพรวม
โมดูล `math.js` มีหน้าที่จัดการการคำนวณพื้นฐานสำหรับระบบ Automated Quality Gate สิ่งสำคัญคือการคำนวณทั้งหมดจะต้องมีความแม่นยำ ทนทานต่อข้อมูลที่ผิดพลาด (Robust) และต้องไม่ส่งคืนค่าที่ไม่คาดคิด เช่น `-0` หรือ `NaN`

## ข้อกำหนดทั่วไป
1. **การตรวจสอบข้อมูลเข้า**: ฟังก์ชันทั้งหมดที่ส่งออกจากโมดูลนี้ จะต้องบังคับตรวจสอบข้อมูลที่รับเข้ามาอย่างเข้มงวด
   - พารามิเตอร์ทั้งหมดต้องเป็นชนิด `number`
   - พารามิเตอร์ทั้งหมดต้องเป็นตัวเลขที่สามารถคำนวณได้จริง (Finite) ห้ามเป็น `Infinity`, `-Infinity` หรือ `NaN`
   - หากข้อมูลไม่ถูกต้องตามนี้ ฟังก์ชันจะต้องโยน (Throw) `TypeError`

2. **การปรับค่าศูนย์ติดลบ (Negative Zero Normalization)**: การคำนวณคณิตศาสตร์ใน JavaScript บางครั้งอาจให้ผลลัพธ์เป็น `-0` ฟังก์ชันทั้งหมดในโมดูลนี้จะต้องปรับค่า `-0` ให้กลายเป็น `0` ปกติเสมอ ก่อนส่งค่ากลับ

## ข้อกำหนดของแต่ละฟังก์ชัน (Function Specifications)

### `add(a, b)`
- ส่งคืนค่าผลรวมของ `a` และ `b`

### `subtract(a, b)`
- ส่งคืนค่าผลต่างของ `a` ลบด้วย `b`

### `multiply(a, b)`
- ส่งคืนค่าผลคูณของ `a` และ `b`

### `divide(a, b)`
- ส่งคืนค่าผลหารของ `a` หารด้วย `b`
- **ข้อยกเว้น (Exception)**: หาก `b` มีค่าเป็น `0` จะต้องโยน `Error` พร้อมข้อความ "Cannot divide by zero"

### `calculatePercentage(value, total)`
- คำนวณร้อยละที่ `value` มีสัดส่วนจาก `total` (เช่น `(value / total) * 100`)
- หาก `total` เป็น `0` ฟังก์ชันจะต้องส่งค่า `0` กลับมาแทน โดยห้ามโยน Error และห้ามส่งค่า `Infinity`

### `modulo(a, b)`
- คำนวณหาเศษจากการหารตามหลักคณิตศาสตร์ที่แท้จริง (ไม่ใช่แค่เครื่องหมายหาเศษ `%` ของ JavaScript)
- **สูตรคำนวณ**: `((a % b) + b) % b`
- **ข้อยกเว้น**: หาก `b` มีค่าเป็น `0` จะต้องโยน `Error` พร้อมข้อความ "Cannot modulo by zero"

## คำสั่งสำหรับการใช้ AI ตรวจสอบ (AI Auditing Directives)
- **ความปลอดภัยและเสถียรภาพ**: ให้แจ้งเตือน (Flag) ทันที หากพบว่าฟังก์ชันไหนไม่มีการทำ Input Validation
- **ความแม่นยำ**: ให้แจ้งเตือน หากฟังก์ชันไหนลืมปรับค่า `-0` ให้กลายเป็น `0`
- **การสร้าง Unit Test**: ตรวจสอบให้แน่ใจว่า Unit Test ครอบคลุมเคสขอบเขต (Boundary conditions) เช่น ตัวส่วนเป็นศูนย์, ตัวเลขขนาดใหญ่มาก และการใส่ค่าตัวเลขติดลบ
